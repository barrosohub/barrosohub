# Barroso Filho

**Applied AI & Software Engineer** · AI Engineering Specialist at Mutant · Brazil

I have spent more than a decade building software across the stack. Today, I focus on turning generative AI into dependable applications: agents that can use tools, work with real system context, and deliver results that people can inspect and act on.

At Mutant, I work in AI engineering for conversational systems. My work sits where LLMs meet application code, integrations, and operations, including technical investigation across voice and text experiences. I bring the same engineering discipline to AI workflows that I expect from any production service.

## What I work on

- **Agents and LLM systems.** Designing workflows with tools, structured outputs, contextual knowledge, and clear boundaries between model reasoning and application logic. I work with Python, FastAPI, Pydantic, Google ADK, MCP, and API integrations.
- **Investigation and observability.** Connecting runtime evidence with prompts, tool behavior, configuration, and application context to understand what happened in a conversational system and where a failure originated.
- **Data and workflow pipelines.** Turning conversations and other unstructured inputs into validated, usable information through extraction, schema checks, asynchronous processing, and persistence. I design for explicit failure paths, including retries and provider fallbacks where they make sense.
- **End-to-end software delivery.** Building APIs and user-facing applications with Python, TypeScript, React, and related technologies, then handling deployment, monitoring, and troubleshooting in cloud and Linux environments.

## How I approach engineering

I start with the system and its evidence: the user journey, the contracts between components, and what the logs and traces actually show. For AI applications, I care about evaluation, failure handling, latency, cost, security, and the ability to explain a result. I prefer portable architecture and clear integration boundaries so a model or cloud provider can change without forcing a rewrite of the product.

My background spans software architecture, cloud integrations, and production operations. I am **Microsoft Certified** and **GitHub Certified**.
